# Escape Challenge Game

一个基于编程挑战的互动逃脱房间游戏。

## 🎮 游戏概述

完成三个编程挑战，在时间耗尽前逃出房间！

## ⏱️ 游戏机制

- **时间限制**: 30 分钟倒计时
- **挑战数量**: 3 个阶段
- **目标**: 完成所有挑战并逃脱

## 🎯 三个挑战阶段

### Stage 1: 格式化代码
- **任务**: 点击按钮查看代码格式化前后的对比
- **学习点**: 代码可读性和格式化的重要性
- **完成条件**: 点击"Format Code"按钮

**示例**:
```javascript
// Before (未格式化)
function test(){const x=5;if(x>3){console.log("yes")}return x*2}

// After (格式化后)
function test() {
  const x = 5;
  if (x > 3) {
    console.log("yes");
  }
  return x * 2;
}
```

### Stage 2: 调试代码
- **任务**: 找出代码中的 bug 并修复
- **Bug**: 使用 `==` 进行比较导致类型不匹配问题
- **学习点**: 严格相等 (`===`) vs 宽松相等 (`==`)
- **完成条件**: 正确识别应该使用 `===` 和数值类型

**Bug 说明**:
```javascript
// Buggy Code
function validateAge(age) {
  if (age == "18") {  // ❌ 只对字符串 "18" 返回 true
    return "Adult";
  }
  return "Not adult";
}

// Fixed Code
function validateAge(age) {
  if (age === 18) {  // ✅ 严格比较数值 18
    return "Adult";
  }
  return "Not adult";
}
```

### Stage 3: 循环挑战
- **任务**: 编写一个从 0 到 1000（包含）的循环
- **学习点**: for 循环语法和循环条件
- **完成条件**: 输入正确的循环条件（如 `i <= 1000` 或 `i < 1001`）

**示例答案**:
```javascript
for (let i = 0; i <= 1000; i++) {
  console.log(i);
}
```

## 🎨 视觉特性

- **背景**: 网格图案背景，营造技术氛围
- **进度条**: 实时显示完成进度 (x/3)
- **状态指示**: 
  - 未完成: 灰色边框
  - 已完成: 绿色边框 + ✅ 标记
- **倒计时警告**:
  - < 1 分钟: 红色显示
  - < 10 秒: 闪烁动画

1. 从主页点击 "🎮 Play Escape Challenge"
2. 查看倒计时器（30 分钟）
3. 按顺序完成三个挑战
4. 在时间耗尽前逃脱！

## 💡 教育价值

这个游戏教授以下编程概念：
1. **代码格式化**: 保持代码整洁和可读
2. **调试技巧**: 识别和修复常见错误
3. **循环逻辑**: 理解循环条件和边界情况
